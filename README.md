# 딸깍 서바이벌

1인 개발자가 서비스를 운영하며 발생하는 이슈를 선택지로 해결하고, 돈과 체력을 관리하는 픽셀 스타일 웹 게임입니다.

## 로컬 실행

Node.js와 pnpm이 필요합니다. 프로젝트를 받은 뒤 VS Code 터미널에서 아래 명령을 실행합니다.

```bash
cd web
pnpm install
pnpm dev
```

터미널에 표시되는 주소(기본값 `http://localhost:5173/ddalggak/`)를 브라우저에서 열면 됩니다.

코드 검사와 배포용 빌드는 다음 명령으로 확인합니다.

```bash
cd web
pnpm typecheck
pnpm build
```

## 현재 구현 내용

- 방 안의 사물을 클릭하면 캐릭터가 사물 앞으로 이동합니다.
- 이슈 선택지를 고르면 캐릭터가 작업 책상으로 이동한 뒤 결과를 처리합니다.
- 돈이 0 이하가 되면 파산 엔딩, 체력이 0 이하가 되면 번아웃 엔딩이 표시됩니다.
- 엔딩 조건은 `web/src/game/endings`에, 게임 상태와 엔딩 처리는 `web/src/core/Session.ts`에 분리되어 있습니다.

개발 환경에서는 아래 주소로 엔딩 화면을 바로 확인할 수 있습니다.

- 파산: `http://localhost:5173/ddalggak/?ending=bankrupt`
- 번아웃: `http://localhost:5173/ddalggak/?ending=burnout`

## 아직 구현되지 않은 부분

침대, 냉장고, 문 같은 일반 사물은 클릭과 이동까지만 동작합니다. 캐릭터가 도착하면 현재는 개발자 콘솔에 상호작용 로그만 남으며, 말풍선·대사·체력 회복·시간 소모 등의 실제 행동은 아직 연결되지 않았습니다.
